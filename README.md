# 📝 React Notes App

> A modern, feature-rich notes application built with React, Redux, Material-UI, and TailwindCSS. Organize, highlight, and manage your notes with ease.

## 🚀 Demo

- **GitHub Pages:** [johnrusu.github.io/react-notes](https://johnrusu.github.io/react-notes/)

## ✨ Features

### 🎨 **User Interface**

- **Dark/Light Mode** - Toggle between themes for comfortable viewing
- **Responsive Design** - Fully optimized for desktop and mobile devices
- **Dynamic Colors** - Text color automatically adjusts based on note background
- **Smooth Animations** - Elegant transitions and loading animations

### 📌 **Note Management**

- **Create & Edit Notes** - Add notes with custom colors
- **Highlight Important Notes** - Mark notes as highlighted for quick access
- **Delete Notes** - Remove notes with confirmation dialog
- **Color Picker** - Choose from preset colors or custom colors for notes

### 🔍 **Organization & Filtering**

- **Text Search** - Filter notes by content in real-time
- **Category Filtering** - View all notes, simple notes, or highlighted notes
- **Drag & Drop Reordering** - Reorganize notes with intuitive drag-and-drop
- **Auto-Sorting** - Highlighted notes automatically appear first

### 💾 **Data Persistence**

- **LocalStorage Integration** - Automatically saves notes and preferences
- **Auto-Clear Timer** - Optional storage cleanup after specified time
- **State Management** - Powered by Redux Toolkit for reliable state handling

## 🛠️ Tech Stack

- **Frontend:** React 19 + TypeScript
- **State Management:** Redux Toolkit
- **UI Framework:** Material-UI + TailwindCSS
- **Build Tool:** Vite
- **Styling:** SCSS + CSS Modules
- **Drag & Drop:** react-dnd
- **Animations:** Lottie React

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/johnrusu/react-notes.git

# Navigate to project directory
cd react-notes

# Install dependencies
npm install

# Start development server
npm run dev
```

## 🏗️ Build & Deploy

```bash
# Build for production
npm run build

# Preview production build
npm run preview

# Deploy to GitHub Pages (automated via GitHub Actions)
git push origin main
```

## 📝 Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
- `npm run lint` - Run ESLint
- `npm run format` - Format code with Prettier
